# 🌸 Club de Literatura Doki Doki

Página web interactiva inspirada en **Doki Doki Literature Club**, creada con un nivel técnico superior.

## ✨ Características

### Interactividad avanzada (JavaScript)
- Sistema de diálogo con las 4 chicas del club (efecto typewriter)
- Navegación con teclado (flechas ← →, Escape, tecla P)
- Drag & Drop de palabras para crear poemas
- Clic para agregar/eliminar palabras
- Validación de formulario en tiempo real
- Persistencia con `localStorage` (nombre de usuario, poemas guardados, membresía)

### Estilo avanzado (CSS)
- Layouts modernos con **CSS Grid** y **Flexbox**
- Animaciones con `@keyframes` (partículas flotantes, typewriter, hover, etc.)
- Transiciones suaves y micro-interacciones
- Diseño **100% responsivo** con media queries
- Variables CSS personalizadas (paleta pastel inspirada en DDLC)
- Fuentes de Google Fonts (Quicksand + Playfair Display)

### API externa gratuita
- **PoetryDB** (`https://poetrydb.org/random`) — Poema aleatorio del día
- Sin API key requerida, CORS habilitado

### Personalización
- Ingreso de nombre del usuario (se guarda en localStorage)
- Saludo personalizado
- Colores pastel personalizados (rosa, púrpura, azul, verde)

## 🚀 Cómo usar

1. Clona o descarga este repositorio
2. Abre `index.html` en tu navegador (o usa un servidor local)
3. ¡Disfruta del club!

```bash
# Servidor local opcional
npx serve .
```
